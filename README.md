# Luiz Bon

I lead architecture direction and delivery across multiple engineering teams at Prospa, a small-business lender in Sydney, alongside an Engineering Manager's day job. Twenty years in software, ten of them hands-on before I moved into leadership. I still make the architectural calls and stay close enough to the code to be useful during an incident.

Recent work: a zero-downtime migration of a core lending platform with 100% financial data integrity, a shared internal .NET SDK I created and still maintain across teams, and an internal MCP registry with an agentic security review gate in CI, so engineers get AI tooling without it becoming a supply-chain or data-exposure problem.

**Stack:** C#/.NET, Azure, event-driven architecture (Service Bus, sagas, outbox), DDD, microservices, OpenTelemetry, Terraform.
